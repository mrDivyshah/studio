# **App Name**: Electro Hub

## Core Features:

- Homepage: Visually attractive and modern homepage featuring the business name, slogan, a high-quality banner/hero section, partner companies, and a call-to-action button to contact via WhatsApp.
- Product Listing Page: Display a grid or card layout of electric wholesale products with images, names, descriptions, and prices, with optional in-stock indicators.
- About Page: Section describing the business history, mission, and values, along with the owner's profile and optional testimonials.
- Contact Form: A contact form with fields for Name, Email, Phone, and Message, redirecting or opening WhatsApp with a pre-filled message on submission to contact the owner directly.
- Location and Timing: Show the business location via an embedded map and clearly mention business working hours.
- Responsiveness: Ensure the website is fully responsive and works seamlessly on mobile devices, tablets, laptops, and desktops.
- SEO Optimization: Implement SEO best practices with Head metadata for all pages and use clean and semantic HTML. Utilize Next.js Image component for optimized image loading.

## Style Guidelines:

- Primary color: Saturated blue (#2962FF) to convey trust and reliability in the electrical wholesale business.
- Background color: Light gray (#F0F4F9), for a clean and modern aesthetic.
- Accent color: Violet (#7F00FF), creating visual interest and highlighting key interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern, machined look. 
- Code font: 'Source Code Pro' for displaying any code snippets.
- Use sharp, modern icons relevant to electrical components and business operations.
- Implement a clean, grid-based layout for product listings and other content sections to ensure readability and ease of navigation.
